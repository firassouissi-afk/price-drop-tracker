# Price-Drop Tracker

Scrapes a configured e-commerce page, stores price history in SQLite, and reports when the price decreases.

```powershell
pip install requests beautifulsoup4
python main.py "Product" "https://example.com/product" ".price"
```

Use only sites that permit scraping and respect their terms and robots rules.
